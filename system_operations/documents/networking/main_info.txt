Ethnet:

1. On PC Create a new wired connection
2. Add a adresses in ipv4 with an address of: 192.168.55.2 a netmask of: 255.255.255.0 and a gateway of: 192.168.55.1

3. Add a new wired connection on the jetson
4. Add a adresses in ipv4 with an address of: 192.168.55.1 a netmask of: 255.255.255.0 and a gateway of: 192.168.55.1






COMMANDS:

CHECK FOR ETHNET WIRE LINK: sudo ethtool eno1

FIXES:
------------------------------------------------------
Both the jetson and pc must have the same ethnet bit rate, run this on both platforms.
------------------------------------------------------

sudo ethtool -s eno1 speed 100 duplex full autoneg off

------------------------------------------------------
Assign a static ip address to both the jetson and your PC, this will set up everything (DO NOT TOUCH WIRED CONNECTION AFTER)
------------------------------------------------------
(JETSON)

sudo ip addr flush dev eno1
sudo ip addr add 192.168.55.1/24 dev eno1
sudo ip link set eno1 up

(PC)

sudo ip addr flush dev eno1
sudo ip addr add 192.168.55.2/24 dev eno1
sudo ip link set eno1 up


sudo ip link set eno1 down
sudo ip addr flush dev eno1
sudo ip link set eno1 up
sudo ip addr add 192.168.55.2/24 dev eno1
sudo ethtool -s eno1 speed 100 duplex full autoneg off
