This script sends initaliztion data to arduino for displaying. i.e. the ip address of the connected network.

----------------------------------------------------------------------
1. Add script and startup files to jetson, and make py file execyable
----------------------------------------------------------------------

sudo nano /etc/systemd/system/startup_data.service

sudo nano /usr/local/bin/startup_data.py
sudo chmod +x /usr/local/bin/startup_data.py

----------------------------------------------------------------------
2. Start the startup services
----------------------------------------------------------------------

sudo systemctl daemon-reload
sudo systemctl enable startup_data.service
sudo systemctl start startup_data.service

sudo systemctl status startup_data.service
