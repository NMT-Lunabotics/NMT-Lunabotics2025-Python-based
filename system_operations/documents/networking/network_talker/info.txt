This is the jetson networking package, this is the package used to talk between the 
jetson and Driverstation during normal operations, and is planned to be how all commucation works. 
This class includes the following methiods:


run_command(command)
------------------------------------------------------------
This is an internal methiod that executes commands, allowing the 
Driverstation to execute commands inside of the docker shell terminal.



send_datasend_data(message, address) (TODO)
------------------------------------------------------------
This is the planned methiod that the jetson will use to send data
back to the driver station, like voltage data or camera data.



receive_data()
------------------------------------------------------------
This is a function that is called in a loop that just listens to 
the data from the Driverstation, messages starting with (CMD:) 
will get executed in the shell terminal
