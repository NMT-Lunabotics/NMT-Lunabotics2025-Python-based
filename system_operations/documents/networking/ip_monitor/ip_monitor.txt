This script sends initaliztion data to arduino for displaying. i.e. the ip address of the connected network.

----------------------------------------------------------------------
1. Add script and startup files to jetson, and make py file execyable
----------------------------------------------------------------------

sudo nano /usr/local/bin/ip_monitor.py
sudo chmod +x /usr/local/bin/ip_monitor.py

sudo nano /etc/systemd/system/ip-monitor.service

----------------------------------------------------------------------
2. Start the startup services
----------------------------------------------------------------------

sudo systemctl daemon-reload
sudo systemctl enable ip-monitor.service
sudo systemctl start ip-monitor.service

sudo systemctl status ip-monitor.service
