To add/remove packages from docker containor add your package to the (Dockerfile)
--------------------
To add system packages add the package name under (RUN apt-get update && apt-get upgrade -y \) with a backslash

To add python packages add the package name under (RUN pip install --no-cache-dir \) with a back slash

To install a repositroy add the package name uder (RUN curl -fsSL https://raw.githubusercontent.com/arduino/arduino-cli/master/install.sh | sh)
