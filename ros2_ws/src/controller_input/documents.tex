Arm button (Left Trigger): Must be held down to be able to run any "dangerous" commands like motor/actuators. 
Non-dangerous functions like camera switch do not require it.

Actuators (Left Joystick): Verticle moves arms up/down, horizontal moves bucket up/down.

Motors (Right Joystick): Verticle moves forword/backword, horizontal turns left/right. 

Camera (Start and Right Joystick Button): Start switches camera, while Right Joystick Button just toggles view while held.

Automations (Back + [X, A, B, or Y]): Start automated functions.







# Button combos: 
# RIGHT_BUMPER+[BUTTON_A,BUTTON_B,BUTTON_X,BUTTON_Y] triggers automation
# LEFT_BUMPER+(LEFT_STICK_BUTTON and RIGHT_STICK_BUTTON) gets robot out of error mode
# LEFT_BUMPER+(BUTTON_Y) shows ip address on screen
# LEFT_BUMPER+(BUTTON_X) Shows last error arduino if any
